No seu computador

Um laboratório em três passos.

Guia completo ↗

Você precisa de Git, Docker Desktop (ou Docker com Compose) e um celular Android ou emulador.

  1. 1

    Clone o repositório

    Baixe o código e entre na pasta do projeto.

  2. 2

    Inicie os serviços

    Execute docker compose up --build -d. Na primeira vez leva alguns minutos. Depois, abra http://localhost:8080: este site passa a rodar no seu computador.

  3. 3

    Conecte o aplicativo

    No app, toque em Ajustes → Outro servidor e use http://IP_DO_COMPUTADOR:8080, com o celular na mesma rede Wi-Fi. No emulador: http://10.0.2.2:8080.

Comandos do terminal
git clone https://github.com/Bruno70i/APS---8-SEMESTRE.git
cd APS---8-SEMESTRE
docker compose up --build -d
docker compose ps

Para encerrar: docker compose stop. O Nginx na porta 8080 reparte os celulares entre as duas APIs, como na VPS.

O APK usa a VPS por padrão. Ao terminar, volte ao Servidor oficial nos Ajustes.
